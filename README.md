# NS-Hire.com

## About the Project
**NS-Hire.com** is a job portal website designed to connect job seekers with employers. The platform allows candidates to search and apply for jobs while enabling companies to post job listings and manage applications efficiently.

## Built With
- **HTML** – Structure and layout
- **CSS** – Styling and responsiveness
- **JavaScript** – Interactive features
- **PHP** – Backend functionality
- **MySQL** – Database management

## Features
- User registration and login (Candidates & Employers)
- Job posting and application management
- Resume upload functionality
- Admin dashboard for managing users and job listings
- Responsive design for mobile and desktop

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Anika2121/NS-Hire-com.git
   ```
2. Move to the project directory:
   ```bash
   cd NS-Hire-com
   ```
3. Set up the database:
   - Import the provided **MySQL database file** into your local database.
   - Update database credentials in the configuration file (`php/config.php`).
4. Start a local server using XAMPP or any PHP server.
5. Open the project in your browser:
   ```
   http://localhost/NS-Hire-com
   ```
